# Serhat Arslan

Software for commerce, data and everyday operations.

[Türkçe](https://github.com/arslanserhat/arslanserhat/blob/main/README.tr.md)

I'm a developer based in Istanbul. My work brings together software development and hands-on e-commerce operations: product information, inventory, pricing, orders and reporting. I like turning a repeated task or an unclear process into something a team can run, inspect and maintain.

## What I work on

- **Business applications:** web interfaces, internal panels, forms and approval workflows.
- **Data workflows:** Python automation, structured files, SQL reports and checks between systems.
- **Integrations:** API connections and the data mappings behind commerce and ERP workflows.
- **Multilingual interfaces:** responsive layouts, language selection and right-to-left experiences.

My main tools are **Python, Django/FastAPI, React/Next.js and SQL**. I also use **PHP/Laravel** for business panels. I choose the implementation around the existing system and the task rather than making every project fit the same stack.

## Product and workflow work

**[eTahlil](https://www.etahlil.com.tr)** is a multilingual digital product I founded and continue to develop. My work includes product scope, web interfaces, data-processing workflows and ongoing improvements. Public interface examples cover onboarding, language selection, mobile layouts and Arabic RTL.

**Fulfillment Hub — in development** covers dealer purchasing, inventory ownership, warehouse handoffs and dispatch workflows. I work on the business rules, application flows and integration requirements. Some ERP and channel connections are still being developed; the workflow screenshots use sample data.

## Selected public repositories

- **[AION2 Global Translator](https://github.com/arslanserhat/AION2-Global-Translator)** — A desktop localization tool for AION2Steam text resources. It supports offline JSON translation files and LibreTranslate-compatible providers, with reuse of existing translations during updates. Setup and third-party components are documented in the repository.
- **[Harf Adası](https://github.com/arslanserhat/harf-adasi)** · [Live demo](https://arslanserhat.github.io/harf-adasi/) — A Turkish literacy and numeracy practice app with teacher-defined word lists, story-based activities and a touch-friendly writing studio. Built with Laravel and JavaScript/Vite, with server-hosted and static build modes.
- **[borsa-indikator](https://github.com/arslanserhat/borsa-indikator)** — An experimental Next.js/TypeScript project for market dashboards, technical indicators, watchlists and portfolio workflows. It includes data-integration and simplified historical-signal backtesting code.
