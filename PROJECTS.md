## eTahlil / e-Sonuç+

**Focus:** Multilingual document and report workflows  
**Stack:** Next.js · TypeScript · FastAPI · PostgreSQL · Redis · Celery  
**Status:** Public product; ongoing development

A multilingual web product for uploading laboratory documents, processing structured results and presenting accessible explanations. I work across product workflows, web implementation and multilingual UX, including Arabic RTL. The application combines Next.js interfaces with a FastAPI backend, document-processing and report modules, dashboards and public educational content.

[Explore the product](https://www.etahlil.com.tr)

The portfolio describes software and interface work; clinical validation is not claimed.

## Fulfillment Hub

**Focus:** B2B commerce and warehouse operations  
**Stack:** React · TypeScript · Vite · NestJS · Prisma · PostgreSQL  
**Status:** In development

A B2B application connecting dealer-facing purchasing with warehouse operations. The implemented workflows cover products and stock, orders, role-separated dashboards, warehouse wave planning, pick lists and barcode checks for picking and packing. My work brings business rules, application flows and integration requirements together in one operational product.

ERP and channel connections are being developed; end-to-end production readiness is not presented as complete.

## Ciro Master

**Focus:** Commerce operations and ERP reporting

## Export Product Catalogue

**Focus:** Product information, images and catalogue publishing  
**Stack:** React · Laravel · PHP · Excel import · jsPDF  
**Status:** Application implementation

A web application for maintaining export product information and preparing shareable catalogues. ## BizReports

**Focus:** Web analytics and scheduled reporting  
**Stack:** Python · Google API clients · Search Console · MySQL Connector · pandas  
**Status:** Historical reporting scripts

Python scripts for daily and monthly page-level reporting, combining web-analytics metrics with Search Console click, CTR and position signals. The source includes command-line entrypoints, rate-limited API calls and report-storage interfaces. This project represents earlier work in data collection, normalisation and recurring reports.

Historical APIs and dependency versions require compatibility review before reuse.

## Clinic Website & Content Workflows

**Focus:** Service content, enquiry forms and publishing  
**Stack:** Python · Django · Templates · CKEditor · Sitemaps  
**Status:** Legacy web project

A Django website combining service information, enquiry forms and a blog. The implementation covers home, about and contact pages, server-side form handling, paginated articles, rich-text posts, generated slugs and sitemap support. It represents my experience with server-rendered websites and content workflows.

Some custom editorial actions remain unfinished. The project is a historical website case, rather than a current clinic-management platform.

## Mobile Game Lab

**Focus:** 3D web and mobile game prototyping  
**Stack:** TypeScript · Three.js · Vite · Capacitor  
**Status:** Prototype

A TypeScript and Three.js 3D game prototype with a WebGL renderer, state-based screens, character/model preloading, arena enemy spawning and upgrade systems. It includes Vite tooling and a Capacitor Android packaging configuration, bringing application architecture into interactive browser and mobile game development.

<a id="zombie-runner-3d"></a>

## Zombie Runner 3D — Unity Prototype

**Focus:** Third-person gameplay foundations  
**Stack:** Unity · C# · URP · Cinemachine · Input System · Starter Assets  
**Status:** Prototype

A Unity third-person gameplay prototype using C#, URP, Cinemachine and the Input System. It builds on Starter Assets components and includes third-person movement and camera control, collectible feedback, a remaining-item counter and player respawning.
